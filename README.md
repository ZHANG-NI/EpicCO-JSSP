# EpicCO: Job-Shop Scheduling

The solver that [EpicCO](https://github.com/ZHANG-NI/EpicCO) produced for the job-shop scheduling problem, starting from the tabu search of Li, Hao and Wu (HTSFP) (M. Li, J.-K. Hao, and Q. Wu, IISE Transactions, 2026; https://github.com/MINGJIE666/JSP).

## Run

```
mkdir -p bin
bash build.sh bin
bin/solver <instance> <solution> -t <seconds> -seed <seed>
```
